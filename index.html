CricketVision AI: Automated Talent Identification & Biomechanics Analysis

Tech Used: Python, Streamlit, Scikit-Learn, OpenCV, MediaPipe, NumPy, Pandas, Plotly

  • Built a cricket analysis web app where anyone can upload a photo, video, or a spreadsheet of player stats and instantly get useful insights back.
  • Used Streamlit to turn the whole project into a simple website with tabs, buttons, and charts — no coding knowledge needed to use it.
  • Created a "Talent Scout" feature where you upload a CSV file of player stats (like runs, wickets, strike rate) and the app automatically figures out who the top performers are.
  • Used a machine learning model called Random Forest to predict a "talent score" for each player based on their past performance numbers.
  • Added smart column detection so the app understands different spreadsheet formats — for example, it recognizes "runs", "Runs", or "total_runs" as the same thing.
  • Automatically checks whether the dataset is about batting, bowling, or both, and adjusts the scoring method accordingly.
  • Built a Player vs Player comparison tool where users pick any two players and see their stats side-by-side in a table and a bar chart.
  • Added model accuracy checks (like R² score, error rates) so the app can tell you if its predictions are reliable or if the model is overfitting/underfitting.
  • Created an "Image Analysis" feature that uses AI-based pose detection (MediaPipe) to study a cricketer's photo and measure their body posture.
  • Measured key body angles such as elbow bend, knee bend, shoulder alignment, and stance width to judge batting or bowling technique.
  • Compared these measured angles to "ideal" values used by professional players, and gave a score out of 100 based on how close the technique is.
  • Built a "Video Analysis" feature that does the same body-posture check but frame-by-frame across an entire video, not just one photo.
  • Automatically picked the best-performing moments from the video (top 30% of frames) to give a fair final score, ignoring bad or blurry frames.
  • Generated automatic, easy-to-read coaching feedback (like "improve your balance" or "great technique") based on the final score.
  • Added visual, color-coded performance reports (Elite, Good, Average, Needs Improvement) so users can quickly understand results without reading numbers.
  • Used Plotly to create interactive charts and graphs, so users can explore player rankings and comparisons visually.
  • Designed the whole app to work for both batting and bowling analysis, making it useful for many types of cricket players.
