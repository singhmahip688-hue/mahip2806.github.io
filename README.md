🔄 How I Add a New Case Study

This portfolio isn't a one-time build — it's a living platform I update every time I ship new work. Here's my exact process:

**Where it goes:** `index.html` → Projects section → replace the next available "Project X" placeholder block.

**Steps:**
1. Open my Claude Project — it already knows my resume, tech stack, and writing style, so I don't have to re-explain myself each time.
2. Give it the new project in 3 beats: **Problem** (what I was solving) → **What I did** (approach + tech stack) → **What came of it** (result/outcome).
3. Ask it to format the case study to match my existing style: a `**Tech Used:**` line, 5–6 bullet points, and a Live Demo + Code link block using:
   ```html
   <p><strong>Live Demo:</strong> <a href="...">Try it live →</a> | <strong>Code:</strong> <a href="...">GitHub Repo</a></p>
   ```
4. Paste the generated HTML into `index.html`, replacing a placeholder.
5. Commit and push — GitHub Pages updates automatically.
